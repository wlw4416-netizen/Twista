# twista-HP

ディズニーロルカナの非公式多人数戦「ツイン・スターリング」（通称ツイスタ）の紹介サイトです。以前の静的 HTML サイトを Next.js で作り直したものです。

```powershell
cd C:\Users\wlw44\twista-HP
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

公開用の静的ファイルは `npm run build` で `out/` に出ます。旧 GitHub Pages（[Twista](https://wlw4416-netizen.github.io/Twista/)）への載せ替えは、準備ができてからで大丈夫です。

本文・デッキ名・ルールの確定稿は、前サイトと同じく仮の作例を含みます。差し替えたい原稿があればこのフォルダで続けます。
